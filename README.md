📌 About the Project
A fully responsive static awareness webpage built for InAmigos Foundation — a Section 8 registered NGO based in Bilaspur, Chhattisgarh, working across 28 states of India.
The webpage covers the NGO's mission, all 6 flagship projects, social impact, and includes working call-to-action buttons for donations and volunteering.
